# Practice goals

The goal of this exercise is to learn basic Git operations.

## What I practised on this branch

- Forked the upstream repository into my own account.
- Created a separate branch (`practice/thawline-edit`) instead of committing straight to `main`.
- Edited this file, staged the change, committed it, and pushed the branch.
- Opened a pull request back to the original repository.

Nothing touches `main` until the maintainer reviews and merges the pull request.
